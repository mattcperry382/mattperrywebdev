BYU Information Systems Department Dashboard

2023 Provo, UT

For a project management class, I created a small website that uses a Tableau dashboard to track the student employment for a small campus office. In this case, it was the student employees that worked for the IS Department of which program I was a part. It contained a Tableau dashboard that was public facing as well as an password-protected user interface that allowed an admin to add new students as employees or remove existing ones.

It also contained a list of all of the students and contact information for them.

This project demonstrates data visualization skills, Django/Python backend development, and user interface design. The entire project took me about two weeks to finish.
