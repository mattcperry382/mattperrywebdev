Prescription Drug Data

2021 Provo, UT

Created a website to track prescription drug data for the state of Utah. This website was part of a contest to potentially track the opioid crisis in Utah and create a digital database and user interface to properly combat this epidemic.

The project included many technical skills related to database management, backend development, and system design.

As a group of 3 individuals, we implemented a scalable technical solution, earning us 3rd place in this competition.
