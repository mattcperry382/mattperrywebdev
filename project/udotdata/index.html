UDOT Collision Data

2022 Provo, UT

For a second INTEX exercise in my program, as a team of 3 individuals, we developed a web dashboard that contained a database of car crashes within Utah complete with locations where they happened.

The data analytics section contained a model that predict the severity of a crash based on multiple factors. It also contained dashboard that summarized the data on a visual and interactable Tableau dashboard.

The project included many technical skills related to database management, backend development, and data analytics.
